# Silent Microphone

WTTG2 microphone mute mod. Keeps Discord and other apps working.

Игра получает тишину вместо звука микрофона. Настройка «Микрофон» в игре остаётся включённой; код и параметры сложности мини-игр не меняются. Discord, NVIDIA и системный доступ к микрофону не затрагиваются. Это блокировка штатных путей записи внутри WTTG2, а не системный запрет для произвольного EXE.

## Установка и использование

Скачайте ZIP из Releases. Закройте игру и скопируйте `WTTG2.SilentMicrophone.dll` в `BepInEx/plugins`. Запустите игру снова. Для отката удалите эту DLL при закрытой игре.

Оставьте «Микрофон» включённым в настройках игры. После установки полностью перезапустите WTTG2: уже запущенный процесс новую DLL не подгружает.

## Исходники и сборка

Сборка требует локальные игровые библиотеки и BepInEx 5.4.23.5; они не включены в репозиторий.

```powershell
.\build.ps1 -GamePath "D:\Games\Welcome to the Game II"
```

## Проверка

В изолированном Unity-процессе проверены четыре пути запуска записи, включённая опция Mic, нулевой уровень и буфер, отсутствие записи физического микрофона. Полные мини-игры и реальный Discord-стрим отдельно не проверены.

Проверено на Windows x64, Unity 2017.3. Для BepInEx-плагинов используется BepInEx 5.4.23.5. Совместимость с другими версиями игры не гарантируется.
